# OverviewPanel

A page's Overview: the kit's **Panel** "Overview" in the column beside the
page, in the comments' place, holding the page's Initiatives, as Ship's
Overview holds a project's (ONE-5, step 5; Katerina, 23 November).

**Seen in**: *Pages/OverviewPanel*: **With initiatives**, **Empty**; *Pages/File
page*: **Overview Open** (press the header's side-panel button again and the
comments come back).

## When

- Beside a page, when the header's side-panel button ("Show side panel") is
  pressed. It takes the comments' place, and hiding it brings back what the
  column held before (`useSideColumn`).

## When not

- Not for the comments. They are the column's other occupant,
  **CommentsColumn**, the kit's one column.

## How

```tsx
import { OverviewPanel } from './OverviewPanel'

{overview.open && (
  <>
    <Divider orientation="vertical" />
    <div className="flex flex-none flex-col" data-overview-column>
      <OverviewPanel topics={takesInitiatives(file.address) ? <FileTopicsOf address={file.address} /> : undefined} />
    </div>
  </>
)}
```

## What it owns

- **Its name**, "Overview", in the panel's bar.
- **Its Initiatives**: the kit's **SectionHeader** "Initiatives", 16px under
  the bar, its 8px inset brought to the panel's 16px edge, and the page's
  `FileTopicsOf` under it, as Ship's Overview places a project's.
- **Its empty line**, "Nothing here yet.", the kit's **EmptyState** for one
  part of a page, for a page no initiative can list (no address, or an
  initiative itself).
- **Its width**: 384px, the comments column's, so the page does not move
  when one replaces the other.
