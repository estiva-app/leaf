# ReferenceChip

A `nostr:` reference to a file where it was written: the package's InlineChip
with the file's kind icon and its name, the whole name on hover.

**Seen in**: a file named in a comment in the comments column.

## When

- A file a comment names: the column's card draws it, and so does the comment
  box for a reference it holds.

## When not

- A person → an `@Name` chip, InlineChip's `person` (or `urgent`) tone.
- One of this page's comments, named by `[` → its author and opening words.
- A link in the page's own text → `PageLink`, the kit's chip, row or card where it sits.

## How

```tsx
import { ReferenceChip, ReferencesProvider, useReferences } from '../document/references'

const references = useReferences(uris)

<ReferencesProvider value={references}>
  <ReferenceChip uri="nostr:naddr1…" />
</ReferencesProvider>
```

## What it owns

- **The file's name, cut at 24 characters**, and the whole of it on hover.
- **Anything not read yet, or unreadable**, drawn as its address, quiet, never
  blank. It reads nothing itself: the names come from **ReferencesProvider**.
